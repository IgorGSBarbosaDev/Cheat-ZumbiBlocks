# Mitigações

Ainda não há achado confirmado que justifique uma correção específica.

Quando os testes dinâmicos forem autorizados e reproduzidos, cada entrada deverá relacionar evidência, impacto, código responsável e correção. A prioridade será autoridade do servidor, sanity checks, rate limiting, validação temporal/espacial, redução de informação enviada e logging comportamental — não anti-cheat kernel como substituto para validação server-side.
